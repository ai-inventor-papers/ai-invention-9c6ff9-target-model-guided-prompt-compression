## Full Summary

This artifact downloads LongBench from HuggingFace (Xnhyacinth/LongBench fork), selects 9 representative tasks (3 per category: narrativeqa, qasper, multifieldqa_en for single-doc QA; hotpotqa, 2wikimqa, musique for multi-doc QA; multi_news, gov_report, qmsum for summarization), tokenizes all documents with LLaMA-3-8B tokenizer to compute original token counts, defines compression budgets (2x=50%, 4x=25%, 8x=12.5% retention), and creates stratified splits: 450 examples (50/task) for iteration 1 mini-split and 1300 holdout examples for iteration 2. Output is formatted to exp_sel_data_out.json schema with 9 dataset groups and 1750 total examples, each containing input (context+question), output (ground truth), and metadata fields (task_name, category, original_token_count, compression budgets, split assignment). Schema validation passes. File size 88MB (under 100MB limit). Includes pyproject.toml with pinned dependencies for reproducibility.
